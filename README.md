# 🏎️ Apex Motors

**Apex Motors** is a premium, interactive automotive showroom experience built with **Next.js, React, TypeScript, Three.js, and React Three Fiber**.

The project showcases the fictional **NOVARA GT-E**, a high-performance electric sports car, through an immersive 3D web experience featuring cinematic scroll animations, vehicle customization, dynamic pricing, inventory browsing, finance calculations, and test-drive booking.

The goal of Apex Motors is to explore how modern web technologies and real-time 3D graphics can be combined to create a premium digital automotive experience.

---

## ✨ Features

### 🚗 Interactive 3D Vehicle

Explore the NOVARA GT-E through a real-time 3D experience powered by **Three.js** and **React Three Fiber**.

- Real-time WebGL rendering
- Interactive vehicle presentation
- Dynamic lighting and materials
- Smooth camera transitions
- Performance-focused rendering

### 🎥 Scroll-Driven Experience

The vehicle presentation responds to page scrolling, creating a cinematic product showcase with:

- Scroll-controlled camera movement
- Smooth scene transitions
- Animated content sections
- Motion-based UI elements
- Immersive vehicle reveals

### 🎨 Vehicle Configurator

Users can personalize the NOVARA GT-E by selecting different:

- Paint colors
- Wheel designs
- Performance packages
- Optional upgrades

Pricing updates dynamically based on the selected configuration.

### 📦 Vehicle Inventory

Browse available vehicles and filter inventory based on different vehicle options and specifications.

### 💰 Finance Calculator

Estimate monthly vehicle payments using adjustable:

- Vehicle price
- Deposit
- Finance term
- APR

The calculator updates estimates dynamically as values change.

### 📅 Test Drive Booking

Users can submit a test-drive request through an interactive booking form with a confirmation state.

### 📱 Responsive Design

Apex Motors is designed to provide a consistent experience across:

- Desktop
- Laptop
- Tablet
- Mobile

The 3D experience and interface adapt to different screen sizes while maintaining performance and usability.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project

```bash
cd apex-motors
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

in your browser.

---

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
